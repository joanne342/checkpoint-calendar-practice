### TESTING

* Calendar shows the current month upon opening.
* October 2024 has:
  * A grid of 5 rows x 7 columns.
  * The first row contains Tuesday October 1 - Saturday October 5. Sunday and Monday are either labelled for September 29/30 or are blank.
  * The last row contains Sunday October 27 - Thursday October 31. Friday and Saturday are either labelled for November or are blank.
  * October 8th: Ada Lovelace Day.
  * October 25th: World Lemur Day.
* October 2020 has:
  * October 13th: Ada Lovelace Day.
  * October 30th: World Lemur Day.
* May 2030 has:
  * May 11th: International Binturong Day.
* The following months start and end on these dates, and do not have extra days or padding boxes outside of the weeks they're meant to cover:
  * 2024-12: Sunday (no empty days before) - Tuesday (4 empty days after).
  * 2025-02: Saturday (6 days before) - Friday (1 empty day after).
  * 2025-05: Thursday (4 empty days before) - Saturday (no empty days after).
  * 2026-02: Sunday (no empty days before) - Saturday (no empty days after).
* Functioning previous and next buttons including at the end-points of the month+year selector.
  * The previous and next buttons work flawlessly when going beyond that limit of the end-points to the month+year selector. The UI does not e.g. show an empty string, "undefined", "null", "NaN" or similar if the "current month" or "current year" is displayed anywhere in the UI. The calendar days are correctly shown.
* It has a usable way of jumping to a month+year.
* UI is generated by DOM manipulation, and day generation is dynamic. Everything would work if arbitrary additional days were added to the data file.
* The website scores 100% for accessibility in Lighthouse in the Desktop device mode, for all views in the website
* Unit tests for non-trivial functions:
  - Ada Lovelace Day, October 2024: Finds the second Tuesday (October 8).
  - Ada Lovelace Day, October 2025: Handles the date changing between years (October 14).
  - International Binturong Day, May 2030: Finds the second Saturday (May 11).
  - World Lemur Day, October 2024: Correctly finds the last Friday (October 25).
  - Invalid weekday: Throws an error for an unsupported weekday name.
* The project contains no dead code. All written JavaScript and CSS is used.
